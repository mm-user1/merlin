03 / CONFIGURATION IN FOCUS
Reading this study Execution settings, metric definitions & supplied IS annotation methods

Independent stages

Capital stays continuous within each stage. Every new stage starts flat with the same capital; curves are neither joined nor compounded. Public reports omit HO2 financial data. Unavailable metrics retain their saved reasons.

What the curves show

Equity includes unrealized gross PnL; balance reflects realized cash including fees. Charts retain three-calendar-day observations, mandatory endpoint/gap points and zero anchors. Segments between retained observations are display guides, not observations or intrabar extrema. Cash gaps show known flat cash; price gaps are never filled. MTM drawdown uses every execution-bar close, not intrabar extremes; sampling differs across timeframes. Price uses real closes rebased to each stage’s first real open, on the same percentage scale as the accounts. It is market context, not a costed buy-and-hold account.

Saved metrics

Profit% is final realized balance relative to initial capital. Ann.P% copies the saved annualizedProfitPct field; no financial metrics are calculated by this report. It is unavailable for stages of 30 days or less or non-positive final capital; 31-89 day values carry an asterisk. It uses the full declared stage duration, not the zoomed chart range. MTM Max DD uses full bar-close equity; Balance Max DD uses realized balance. Neither is derived from the chart. Daily Sharpe uses observed UTC days, simple returns, a 2% annual risk-free rate, population variance and √365. Trades/month uses calendar-month equivalents.

Research limits & HO2

Reveal HO2 shows every available HO2 result throughout this report, independently of selection and filters. The same button hides HO2 again and removes HO2 sorting and chart extent; it does not undo exposure. Reloading starts hidden. Owner files embed HO2: hiding is an interface control, not access security. Public files contain no HO2 financial blocks.
